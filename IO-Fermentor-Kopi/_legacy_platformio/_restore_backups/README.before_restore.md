# Archived PlatformIO firmware

This is a recoverable backup of the previous C++ PlatformIO project from
`../Fermentor`. It contains `platformio.ini`, the three C++ source/header
files under `src/`, the generated PIO VS Code settings, and the original
`include/`, `lib/`, and `test/` scaffolding. The Rust firmware is now the
active project at [`../Fermentor`](../Fermentor/README.md).

The generated `.pio` build/library cache was removed; it can be regenerated
from this archived PlatformIO configuration if rollback is ever needed. This
archive was not flashed or otherwise modified as part of the Rust conversion.
